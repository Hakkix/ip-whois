How it works

This tool validates the IP locally, fetches RDAP bootstrap data, follows redirects to the responsible registry, and adds geolocation from public no-auth providers. A DNS hostname is first resolved to an IP address via DNS-over-HTTPS (Cloudflare, then Google), then looked up the same way.
