    About IP Intelligence

    About

    IP Intelligence combines RDAP registration data, ASN/network registration, DNS, reverse DNS, and approximate IP geolocation into a single report for an IP address or hostname.

    Data Sources

    RDAP information comes from the relevant regional Internet registry (ARIN, RIPE NCC, APNIC, LACNIC, or AFRINIC) via RDAP bootstrap. DNS information — forward resolution and reverse (PTR) lookups — comes from DNS-over-HTTPS providers used by this application. Approximate geolocation and ASN data come from external GeoIP providers, tried in order as a cascade. A provider fallback may be used automatically when one source fails. Not every value comes from the same authority.

    Limitations

    • GeoIP location is approximate.
    • Network location is not device or person location.
    • PTR (reverse DNS) records may not exist.
    • Registry data can be stale or incomplete.
    • Different providers can disagree with each other.
    • Hostname lookups may resolve to multiple IP addresses.
    • ASN and GeoIP information can change over time.

    Privacy

    • Your public IP is used only to populate the self-IP display.
    • Session lookup history is kept only for the current browser session (sessionStorage), never persisted.
    • No persistent lookup history is stored by this application.
    • No browser GPS/geolocation permission is ever requested.
    • Queried IP geolocation concerns the investigated IP address, not your physical GPS position.
